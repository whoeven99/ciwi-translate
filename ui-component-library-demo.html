CIWI 组件库基线

          

            这份 demo 不是重新发明组件，而是把现有代码里的稳定结构抽出来，改成纯
            HTML 预览。后续建议流程就是：先在这里调 token，再去 Figma 微调，最后再把确认过的变量回写到代码。
